# 线性代数完全学习指南 · Linear Algebra Tutorial

为**数学基础不好的人**而写的线性代数交互式教学网页。用几何直觉、大量生活比喻、22 个交互演示（含 2 个真3D）、学习路径图、练习题与术语表，让你真正"看懂"线性代数在做什么——而不是死背公式。

## 特点

- 🎯 **零基础友好**：从"向量是什么"讲起，不预设高数基础，每个抽象概念先给画面/比喻，再给公式；前言明确"只需初中代数"
- 🖼️ **几何直觉优先**：矩阵=变形咒、特征向量=北极星、行列式=面积倍数，用可视化建立直觉（受 3Blue1Brown 启发）
- 📖 **全站通俗化**：每个概念配 `.callout-analogy` 生活比喻，砍掉"显然/不难证明"等吓人话术
- 🎮 **22 个交互演示**：含 2 个 Three.js 真3D（正定能量碗可旋转、叉积右手定则）、SVD 图像压缩、Gram-Schmidt 动画、矩阵乘法逐步动画、最小二乘拟合、卷积滤镜实验室、词向量语义算术等
- 🗺️ **学习路径图 + 每章难度标记**：前言有概念依赖 SVG 图，每章有难度星级和预计时长
- ✏️ **练习题 + 术语表 + 公式速查**：核心章有自测选择题，附录有 28 术语索引和 12 公式速查卡
- 💾 **阅读进度记忆**：刷新后自动提示"上次读到哪章"
- 🌙 **暗色科技风**：GitHub Dark 配色，左侧固定导航 + 阅读进度条
- 📱 **完全响应式 + 离线**：手机端自适应，所有资源本地化，双击即开

## 如何运行

**方式一：直接双击（最简单）**

双击 `index.html`，用浏览器打开即可。所有资源都在本地，开箱即用。

**方式二：本地服务器（推荐，避免某些浏览器的 file:// 限制）**

```bash
cd linear-algebra-tutorial
python -m http.server 8000
# 然后浏览器访问 http://localhost:8000/
```

无需 `npm install`，无任何依赖安装步骤。

## 技术栈

- **HTML5 + CSS3 + 原生 JavaScript**：纯静态，零框架、零构建工具、零 npm 依赖
- **KaTeX v0.18.1**（本地化）：数学公式与矩阵渲染（约 400 个公式）
- **Canvas 2D API**：大部分交互演示（线性代数概念以 2D 为主，含矩阵乘法动画、最小二乘拟合、卷积滤镜、词向量算术等）
- **Three.js r128 + OrbitControls**（本地化）：2 个真3D 演示（正定能量碗、叉积右手定则），可拖拽旋转
- **CSS 变量 + Flex/Grid**：设计令牌驱动的暗色主题
- 设计语言与同仓库的 [《实时渲染完全学习指南》](../realtime-rendering-tutorial/) 保持一致

## 设计理念

这份指南针对"数学基础不好的人"，遵循四条教学原则：

1. **动机先行**：每章开头先用真实应用（AI、游戏、图像压缩、搜索引擎）说明"为什么学这个"
2. **几何直觉优先**：每个抽象概念先给可视化/打比方（`.callout-analogy` 组件），再给公式
3. **概念 → 演示 → 公式 → 小结** 四段式结构，每章结尾有要点回顾
4. **大量比喻**：矩阵=变形咒、特征向量=变换中的北极星、行列式=面积变化倍数、线性无关=团队里没有混子……
